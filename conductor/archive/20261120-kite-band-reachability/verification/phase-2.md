## What changed

Added `maintainableGapMm(ownTopSpeed, foeTopSpeed, reachEdge)` to
`packages/sim/src/battle/continuous/controller-reach.ts`. It is a pure, named
export using integer arithmetic only: when the foe is not faster it returns
`Number.MAX_SAFE_INTEGER` (clamp inert), otherwise
`reachEdge + Math.trunc((reachEdge * ownTopSpeed) / foeTopSpeed)`. Speeds are
the `movement.topSpeed` values in thousandths of a mm per ms; no RNG, clock,
network, DOM or floating-point policy decision is involved.

`threatBandFor` applies the clamp only to a Kite-shaped profile (identified by
Kite's authored floor/ceiling band), capping floor, preferred and ceiling at
`maintainableGapMm(...) + REACH_STANDOFF_MM`. The existing reach lift still wins
when the foe threatens beyond that gap, so `floor >= opponentReachMm + 80`
always holds. Movement, frame data, damage, aggression, other doctrines,
species values, fences and balance scripts are untouched. `controller-profile.ts`
is byte-identical to baseline: the 12,288 B module cap leaves it ~18 B of
headroom, so the helper could not live there.
