## Recipe fixes applied to the recovered work

The recovered recipes were geometrically unfinished: parts were swallowed by
bulk volumes, thin features sat on grid lines and claimed nothing, and the
proportion budgets were exceeded across the 200-seed audit. Fixes (recipes
only — no assertion was weakened):

- **frond** — tail moved clear of the rump capsule's rear cap and its tip
  widened so both parts claim voxels; barrel thickened and shortened so the
  body-height ratio lands in budget; legs thickened above 1.5 voxels so the
  coarse audit lattice stops undersampling them; antler beam and tines
  thickened (a capsule axis on a grid line leaves every neighbouring voxel
  centre √0.5 ≈ 0.707 away, so a sub-0.71 radius claims nothing at all).
- **crab** — carapace dome raised so the legs clear it (a hip buried in the
  shell leaves the leg fields empty); leg foot raised off the grid floor;
  spike ridge lifted onto the dome crown and its radius raised past 0.71;
  shell-dressing pivot/color/parent registration de-duplicated (the recovered
  code registered each dressing part twice, inside a stray side loop);
  carapace height floor raised so the dome is not sampled as two rows.
- **smolder** — barrel shortened and lightened, neck raised and thinned so the
  skull reads above the fleece, tail moved clear of the rump and its tip
  widened, juvenile ember tufts changed from spheres buried inside the skull
  box to capsules rising clear of its rear-top corner.
- **`budgets.ts`** — the three recovered budget entries were recalibrated to
  the measured 200-seed audit-lattice sweep (all three stages), with the
  measured spans recorded in the comments, matching how the six existing
  entries are documented.

## Branch-variant handling decision

The three new lines' champion branch forms carry accent tints (fernstag
140/105, reefclaw 200/230, cindermoor 12/2 — pinned in Phase 1's
branch-catalog). **No branch-variant GLBs were generated, and none are
missing.** The voxel pipeline has no branch dimension: `generate(id, seed,
stage)` takes only archetype/seed/stage, and the branch accent is applied at
the client material layer (`apps/client/src/creature.ts` `branchTint()` reads
`getBranch(branch).accentHue` and washes the mesh colour). This is exactly
how the six existing species behave — each has two accent hues in the
branch catalog, yet the committed artifact set is 18 GLBs (6 × 3 stages) with
no branch variants. The new lines therefore extend the set to 27 (9 × 3),
mirroring the existing mechanism rather than inventing a new one.
