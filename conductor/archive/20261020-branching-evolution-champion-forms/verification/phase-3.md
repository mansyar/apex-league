### Tuning

The first probe run failed the bands: an unoriented mirror measured 24% and Thorn Ram vs legacy 80.2%. Two causes were separated. (1) Measurement bias — the resolver's tie order is keyed by fighter name (`makeRng(seed ^ hash(name))`), so a single name/seat orientation measures the hash, not the form; pooling both name assignments and both seat orders cancels it, and identical-sided mirrors then land at 50%. (2) Real imbalance — offense branches out-damaged defense branches and the legacy line. Only Phase 1 `championBoost` rows changed (juvenile boosts, signatures, budgets and every non-branch number are untouched; `branches.test.ts` `CONTRACT` mirrors the table):

| --- | --- | --- |
| cinder_courser | `{ hp: 4, atk: 8, def: 3, spd: 3 }` | `{ hp: 5, atk: 7, def: 3, spd: 2 }` |
| pyre_warden | `{ hp: 7, atk: 3, def: 5, spd: 0 }` | `{ hp: 7, atk: 2, def: 6, spd: 0 }` |
