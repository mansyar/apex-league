## Deviations

- No production code changed in this phase; `git diff --name-only d39b8969..HEAD` was empty before the evidence commits. No dependency, save schema, determinism input or generated artifact changed (NFR-3, NFR-6).
- The Move Lab dropdown is built from the 48 elemental kit moves and cannot select the innate element-less `basic` id. To obtain an honest generic-fallback comparison, an in-page `eval` appended a non-catalog option `unknown_probe` to the real Move select, then the lab's own Trigger/`labStepsFor`/`fxFor` path resolved it through `DEFAULT_FX`. These captures are explicitly **not** lab shots of `"basic"`; the authored Strike shot comes from a real spar.
- The spar verdict stamp reads `A knockout finish.` for both a terminal `ko: true` step and a non-terminal down followed by a reel line, so it is not by itself proof of the terminal branch. Terminal vs ordinary was classified from `buildPlaybackScript`'s rule — the down is terminal only when no non-down/time/draw event follows it — using the real battle log: `phone-ko.png` ends on `Tide Axolotl goes down.` (`ko: true`), while `phone-ordinary-down.png` ends on `Tide Axolotl reels — guard broken.` (`ko: false`). An ordinary down is seed-dependent, so the phone capture looped bouts until both variants appeared.
- The transient dust-ring vs soft-fall animation frame outran screenshot latency (the verdict stamp was already present on the first returned frame), so the visual distinction between the two landing branches is carried by the log classification above plus the phase-2 unit tests that pin impulse, reel and dust-ring behavior. No dust-ring frame is claimed.
- On the phone viewport the top HUD bar (`z-index: 45`) overlaps the Spar chip's pointer box and an onboarding tip covers it on first load. The capture dismissed the tip and invoked the real buttons' DOM `click()` handlers rather than pointer clicks; no app code or CSS was changed to make the flow work.
- Scratch capture scripts and all screenshots live under the gitignored `.conductor/evidence/20261125-basic-strike-identity-impact/` directory; only the two evidence Markdown files are committed.
- The dev server started with `bun run dev` was left running; stopping a shell-spawned process is not in this agent's permitted command set.

## Notes

- The configured gate was run exactly as required: `bun run verify && bun run build` → exit 0. `verify` itself runs `bun run check`, `bun test --check --parallel --timeout 120000`, `biome check` and `bun run gate:determinism`; the table lists those layers separately with the counts from that single run.
- Frame-speed detection used in-page `page.waitForFunction` over the real `.spar-line` battle log, because shell-side polling plus `page.evaluate` missed single-frame beats. The Battle log was toggled open so the "lands Strike" / "goes down." lines remain visible in the captures.

No sim state was hand-crafted: every spar shot came from the real starter save and the real `resolveContinuous` fight. The phone terminal KO came from bout 1 vs Tide Axolotl; the ordinary down came from an earlier bout whose trailing reel line marked it non-terminal.
- Camera/FX comparison uses the lab's own Cinematic camera and 0.1× pace; both fallback and bespoke rows were staged through the same real lab rig with fixed seeds 11/23.
- Prior phase evidence (`phase-1.md`, `phase-2.md`) carries the code-level AC-1/2/3/4/6 pins; this report adds the integrated gate and the player-visible evidence.
