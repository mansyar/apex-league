## What changed

`packages/sim/src/save/migrate.ts` (40,587 B) held all 24 version steps inside one
`migrations` record literal. Each step now lives in its own module under
`packages/sim/src/save/migrations/`, the record is composed in
`packages/sim/src/save/migrations/index.ts`, and `migrate.ts` keeps only the
driver plus the shared primitives.

| File | Role |
|---|---|
| `packages/sim/src/save/migrations/v0.ts` … `v23.ts` | One module per version step, moved verbatim out of the record literal (24 files). |
| `packages/sim/src/save/migrations/common.ts` | `STARTER_GRANT_SEED`, `validateStateShape`, `persistedCreature` — the primitives the steps lean on. |
| `packages/sim/src/save/migrations/index.ts` | The `Record<number, (raw) => Record<string, unknown>>` keyed `0`…`23`; the only place that knows the chain's order. |
| `packages/sim/src/save/migrate.ts` | The `migrate()` driver (unchanged logic) plus the re-export of `STARTER_GRANT_SEED` / `validateStateShape`. |
| `packages/sim/src/save/migrations.test.ts` | New suite locking the chain (exact key list, full traversal, mid-chain start, rejection messages). |
| `docs/save-schema.md` | The two stale `migrate.ts` file references repointed at `packages/sim/src/save/migrations/`. |

No behaviour change: `SAVE_VERSION` stays `24`, the persisted shape is unchanged,
no existing test file was edited, no dependency was added, and
`packages/sim/src/index.ts` is byte-identical (`git status` never lists it).

## Deviations

1. **`packages/sim/src/save/migrations/common.ts` (new file)** — the brief asked to
   keep `STARTER_GRANT_SEED`, `validateStateShape` and the private
   `persistedCreature` helper inside `save/migrate.ts`. They live in
   `save/migrations/common.ts` instead and `save/migrate.ts` re-exports
   `STARTER_GRANT_SEED` and `validateStateShape`
   (`export { STARTER_GRANT_SEED, validateStateShape } from "./migrations/common"`).
   Reason: `save/migrate.ts` imports the barrel, and every step needs these
   primitives — leaving them in the driver would force the steps to import the
   driver (or the barrel) back and close the import cycle the brief forbids
   (NFR-7). The public import path is unchanged: `save/storage.ts`,
   `save/transfer.ts`, `save/save.test.ts` and `packages/sim/src/index.ts` still
   resolve `migrate` / `validateStateShape` from `save/migrate.ts`.
2. **Verification command ordering** — `bun test packages/sim/src/save --timeout 120000`
   is rejected by the environment's shell allowlist (a path argument before the
   flag). The same scope was run as `bun test --timeout 120000 packages/sim/src/save`,
   and `biome check` was run through `bun run verify`. No layer was skipped.
3. **Temporary verification artefacts** — `packages/sim/src/save/migrateOriginalTmp.ts`,
   `migrateDiffTmp.test.ts`, `verbatimTmp.test.ts`, `cleanupTmp.test.ts`,
   `zzCleanupTmp.test.ts` and `zzSizeTmp.test.ts` were created under the repo to
   diff the extracted chain against the pre-refactor implementation and to read
   the byte sizes, then removed. `git status` is clean; none of them is in the
   commit. A scratch cleanup script was also left in the gitignored
   `.conductor/evidence/` folder (`.conductor/evidence/cleanup-phase1-tmp.ts`).
