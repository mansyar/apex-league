The new feathers scale with body/wing/tail proportions (`falcon.ts:177-180,242-247`), and template-max proportions are never combined with style extremes and champion maturity. Current calculations stay inside the 56-grid with margin, so this is test strengthening rather than a demonstrated defect. Fix: add a worst-case proportion set (e.g. bodyGirth 1.3, bodyLength 1.35, wingLength 1.35, tailLength 1.35) to the style/stage/reach matrix, keeping boundary, finiteness and non-degenerate assertions. Requirement: FR-6, AC-2, AC-5.
