## Notes

- P2.T5 is a compile adaptation only: no dock UX change beyond showing the program label as the train tag; the four-stat inline picker and its `at-cap` disabled state are unchanged, and `hud-screen` keeps stat→program mapping until Phase 4.
- The `at-cap` gate reads the program's **primary** stat only; a capped trickle never blocks assignment (verified in `care.test.ts`).
- `trainingDays % 3 === 0` is guarded with `trainingDays > 0` so a hand-built assignment with no trained day behind it cannot pay a trickle; in play the counter always advances with the AP-spending assignment.
- `trainingPlan` is the single source of truth shared by settlement and `previewTraining`, which is why the preview-exactness test can compare against a real `advanceDay`.
- `bunx biome check` and `bun run biome` are both refused by this sandbox, so the formatting rework below was applied by hand from Biome's own diff output (`bun run verify` prints the exact expected content).
- Not touched: `packages/sim/src/battle/`, `packages/sim/src/cup/`, product docs, plan/spec/metadata.
